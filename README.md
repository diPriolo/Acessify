# ♿ Acessify - Aplicativo\ferramenta auxiliar

![Capa do Acessify](Acessify.png)


O **Acessify** é um aplicativo desenvolvido com o propósito de promover a inclusão social por meio da tecnologia, auxiliando pessoas com deficiência ou mobilidade reduzida a encontrarem pontos turísticos acessíveis de forma prática, segura e confiável.

A plataforma foi idealizada a partir da dificuldade real enfrentada por milhões de pessoas ao buscar informações sobre acessibilidade em locais públicos. Com isso, o Acessify surge como uma solução que centraliza dados relevantes, melhora a experiência de locomoção e contribui para uma sociedade mais justa e acessível.

---

## Objetivo

O principal objetivo do projeto é facilitar o acesso à informação sobre acessibilidade em pontos turísticos, permitindo que usuários planejem seus passeios com autonomia, segurança e confiança.

Além disso, o projeto busca:

* Promover a inclusão social
* Incentivar o turismo acessível
* Aumentar a conscientização sobre acessibilidade
* Reduzir barreiras enfrentadas por pessoas com deficiência

---

##  Funcionalidades

O Acessify oferece diversas funcionalidades voltadas à experiência do usuário:

* **Visualização de pontos turísticos acessíveis**
  Exibição de locais com informações detalhadas sobre acessibilidade

* **Mapa interativo**
  Permite explorar locais próximos com base na localização do usuário

* **Sistema de avaliações**
  Usuários podem avaliar locais, atribuir notas e comentar suas experiências

* **Envio de imagens**
  Possibilidade de anexar fotos reais dos locais visitados

* **Filtros avançados de acessibilidade**

  * Rampas
  * Banheiros adaptados
  * Piso tátil
  * Sinalização em braile
  * Entre outros

*  **Sistema de usuários**
  Cadastro, login, edição de perfil e personalização com avatar

*  **Locais salvos**
  Permite favoritar pontos turísticos para acesso rápido


---

## Diferencial do projeto

O Acessify se destaca no mercado por apresentar:

* Foco exclusivo em **turismo acessível**
* Informações detalhadas e específicas sobre acessibilidade
* Abordagem colaborativa (dados gerados pelos próprios usuários)
* Interface intuitiva e pensada para inclusão
* Possibilidade de visualizar experiências reais por meio de avaliações e imagens

Diferente de plataformas generalistas, o Acessify foi projetado especificamente para atender às necessidades de pessoas com mobilidade reduzida.

##  Tecnologias utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

* **Java** → desenvolvimento do aplicativo Android
* **XML** → estruturação das interfaces
* **JSON** → desenvolvimento do banco de dados
* **HTML & CSS** → desenvolvimento do site
* **Firebase** → banco de dados e autenticação
* **Android Studio** → ambiente de desenvolvimento mobile
* **Visual Studio Code** → desenvolvimento web
